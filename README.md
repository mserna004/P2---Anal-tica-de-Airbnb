# P2-Analitica-de-Airbnb
Desarrolla un análisis de datos para determinar el precio de renta de una habitación o departamento en una ciudad del mundo y definir cuáles propiedades son o no recomendables rentar.  De manera independiente y autosuficiente identifica patrones e interacciones relevantes de la información que provee la plataforma tecnológica Airbnb.

## Datos
Fuente: Inside Airbnb, Clark County, Nevada. Fecha de corte: 2026-09-20.
Archivo: listings.csv.gz (descargar de https://insideairbnb.com/get-the-data/).

## Estructura del repositorio
- etapa1_planeacion: project charter y planeación del análisis.
- etapa2_limpieza_datos: cuaderno de limpieza y resumen del dataset final.
- etapa3_analisis_exploratorio: análisis exploratorio de datos.
- etapa4_modelos_predictivos: modelos de predicción y clasificación.
- etapa5_tablero: código del tablero.
- etapa6_despliegue: archivos para lanzar el tablero en un contenedor.
- etapa7_evaluacion: evaluación de los resultados.
- etapa8_presentacion: presentación final.
